# Paginação

Navega entre páginas de resultados (numerada) ou entre destaques de um carrossel (pontos).

- `nav.sdb-pages`: cápsula de vidro com botões circulares; a atual em `prominent-fill` com `aria-current="page"`. Mostra primeira, última, atual e vizinhas; o resto vira "…". Abaixo de 520 px vira "Página 5 de 12".
- `.sdb-dots`: o ponto atual se alonga em cápsula com mola.
