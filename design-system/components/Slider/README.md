# Slider

Valor dentro de um intervalo contínuo, como período histórico ou tamanho de leitura.

- `<input type="range" class="sdb-slider" data-format="{v} px">` + `<output data-slider-out="id">`.
- Trilho de 6 px (`fill-strong`, preenchido em `accent-fill`), polegar branco de 28 px com `shadow-knob` que cresce 10% ao arrastar.
- Mostre sempre o valor atual e as extremidades (texto ou ícones pequeno/grande).
