# Checkbox

Seleciona zero ou mais opções independentes.

- `<label class="sdb-check"><input type="checkbox"> <span>Rótulo <small>ajuda</small></span></label>`. Quadrado de cantos 7 px; `.sdb-check--circle` para listas de tarefa.
- Marcado: `accent-fill` com marca `on-accent` que entra com mola. Misto: `indeterminate`. Erro: `.is-error`. Desabilitado: 40%.
- Em listas agrupadas prefira a linha com marca à direita (`.sdb-option`, ver Filtros de busca).
