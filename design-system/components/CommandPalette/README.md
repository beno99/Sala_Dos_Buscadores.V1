# Command palette

Atalho de teclado para ir a qualquer Sala, tema ou ação, como o Spotlight.

- Abre com ⌘K / Ctrl K, **sem animação**: é usado dezenas de vezes por dia e o movimento o faria parecer lento.
- Painel em material espesso, campo de 21 px, grupos Salas · Temas · Ações. Cada item tem um disco à esquerda (arco para Salas, ícone para o resto) e atalho à direita.
- Filtra por início de palavra, ignorando acentos. Setas movem a seleção (`accent-fill`); Enter executa; Esc limpa.
- Sem resultado: "Nenhum resultado para 'x'. Tente um tema, como alma."

## Paleta areia (out 2026)
No Sólido claro, a superfície leva o degradê dourado `overlay-from` → `overlay-to` (Figma "Jornada do buscador"); listas e itens em foco por dentro usam `overlay-inset`. Nos outros temas, o material de antes.
