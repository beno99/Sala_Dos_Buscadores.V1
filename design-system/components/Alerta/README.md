# Alerta

Mensagem persistente na página, ligada ao conteúdo ao redor.

- **Informativo**: material regular, disco `fill` com ícone `info`.
- **Atenção** `--warning`: disco de ouro com glifo preto (`gold` + `on-gold`).
- **Erro** `--error`: fundo `critical-soft`, disco bordô, `role="alert"`.
- Título começa pelo tipo quando o ícone não basta ("Atenção:", "Erro:"). Diga o que aconteceu e o que fazer.
