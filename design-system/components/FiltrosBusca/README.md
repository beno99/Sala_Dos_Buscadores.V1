# Filtros de busca

Refinam os resultados por Sala, tema, nível, tipo de conteúdo e formato.

- Painel em material com lista agrupada; cada grupo é um item de Accordion.
- Sala, nível e tipo: linhas `.sdb-option` com contagem e marca à direita (padrão de listas da Apple). Tema: Chips. Formato: segmentado.
- Filtros ativos aparecem no topo como chips removíveis; "Limpar" zera tudo. O botão principal mostra a contagem ao vivo ("Ver 24 resultados").
- Em telas estreitas o painel vai para um Drawer aberto por "Filtros (n)".
- Sem resultados: diga qual filtro remover.
