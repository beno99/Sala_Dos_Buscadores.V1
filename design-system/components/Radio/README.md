# Radio

Escolha única quando todas as opções cabem na tela (até 5).

- `<fieldset class="sdb-fieldset">` com `legend`; `<label class="sdb-check"><input type="radio">`.
- Selecionado: disco `accent-fill` com ponto `on-accent`. Estados: padrão, selecionado, foco, desabilitado.
- Para 2–4 opções curtas que mudam a vista, use o controle segmentado (Tabs).
