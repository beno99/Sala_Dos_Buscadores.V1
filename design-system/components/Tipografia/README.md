# Tipografia

O acervo fala em serifa; a interface e a IA falam em Inter.

- **Marca** `display-caps` (Gambetta, caixa-alta): `.sdb-display-xl`, `.sdb-display-l`. Uma vez por tela.
- **Editorial** `display-lower` (Hident; Fraunces até a entrega dos arquivos): `.sdb-large-title` (56), `.sdb-title-1` (34), `.sdb-title-2` (24). Tracking negativo (−2% a −1%) e entrelinha curta, como a Apple faz em tamanhos grandes.
- **Leitura** `reading` (Source Serif 4): `.sdb-body` 19/1.6, `.sdb-body-sm` 16/1.55. Citações em `quote` 26.
- **Interface** `ui` (Inter): `.sdb-headline` 17 semibold, `.sdb-callout` 15, `.sdb-footnote` 13. Inter é a fonte de sistema do portal (papel do SF Pro).
- **Meta** `.sdb-meta`: 11,5 px, caixa-alta, +6%. Só para rótulos de seção e localização de fonte.
- Hierarquia por peso + tamanho + entrelinha juntos. Campos de texto com 16 px ou mais.
