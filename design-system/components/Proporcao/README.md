# Proporção

Quanto de cada cor aparece em uma tela e quais pares de texto são permitidos.

- 60% `bg-canvas`, 25% `depth-fill` (bordô), 10% texto (`label`), 5% `gold`.
- Texto sobre fundo, somente: grafite sobre bege (ou branco), bordô sobre bege, branco sobre grafite, bege sobre bordô. `label`, `accent`, `on-accent`, `on-prominent` e `on-depth` já resolvem isso nos quatro temas.
- Ouro é emblema, filete ou progresso sobre placa escura, com glifo preto quando carrega ícone. Nunca texto, nunca fundo de leitura.
