# Switch

Preferência de efeito imediato, sem botão de salvar.

- `<input type="checkbox" role="switch">` dentro de `.sdb-switch`. Em listas, a linha inteira (`label.sdb-option`) é clicável, com o switch à direita.
- 51 × 31 px. Ligado: trilho `accent-fill`, polegar `knob-on`. O polegar desliza com mola e se alonga enquanto pressionado.
- Para escolhas que só valem depois de "Salvar", use Checkbox.
