# Verbete de glossário

Termo de uma tradição com origem, definição atribuída e as Salas onde aparece, organizado por letra.

## O consumidor fornece
Termo, língua/escrita original/tradução literal, definição atribuída a uma fonte ("Nos textos de…", "No Corpus Hermeticum…"), Salas relacionadas e, se houver, remissões.

## Comportamento
- Índice A–Z em botões de 42 px; letras sem verbete ficam desabilitadas. A letra ativa usa `prominent-fill`.
- Cada verbete é um card de material com accordion; o primeiro da letra abre sozinho. Os cards entram em cascata curta (40 ms).
- Rodapé em `footnote`: quem redigiu o verbete.
- Definições descrevem o uso na tradição; nunca afirmam o que "é verdade". Um termo com sentidos diferentes em Salas diferentes ganha um parágrafo por Sala.
