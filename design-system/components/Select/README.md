# Select

Escolha única com o `<select>` nativo (teclado, leitor de tela e roda nativa no iOS).

- `.sdb-control` > `select` + ícone `chevronDuplo` (padrão dos menus pop-up da Apple).
- Até ~12 opções. Listas longas ou com busca: Command palette ou Filtros de busca.
- Estados: padrão, foco, erro, desabilitado.
